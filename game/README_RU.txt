ЭТАП 1 — ГЛАВНОЕ МЕНЮ REN'PY

СОДЕРЖИМОЕ
- z_custom_ui.rpy — переопределение главного меню и базовые стили кнопок.

КАК УСТАНОВИТЬ
1. Сделайте резервную копию проекта Ren'Py.
2. Откройте папку проекта, затем папку game/.
3. Скопируйте туда файл z_custom_ui.rpy.
4. Запустите проект через Ren'Py Launcher.
5. Проверьте главное меню: кнопки должны открывать стандартные экраны Ren'Py.

ВАЖНО
- Файл не заменяет screens.rpy и не требует удаления стандартных файлов.
- Если проект уже содержит собственный экран main_menu в другом файле, возможен конфликт. В таком случае сообщите об ошибке — подстроим подключение под структуру проекта.
- Заголовок «НАЗВАНИЕ ИГРЫ» пока временный.
- Фон пока однотонный; иллюстрацию добавим позднее.
- Разрешение 1920×1080 нужно отдельно зафиксировать в options.rpy, если оно ещё не установлено.

НАСТРОЙКА РАЗРЕШЕНИЯ
В options.rpy найдите строки config.screen_width и config.screen_height и задайте:

define config.screen_width = 1920
define config.screen_height = 1080

Если таких строк нет, добавьте их в options.rpy рядом с другими настройками config.
Не создавайте дубликаты, если эти параметры уже объявлены.

ПРОВЕРКА
- [ ] Проект запускается без ошибок.
- [ ] Отображаются шесть пунктов меню.
- [ ] «Новая игра» запускает сценарий.
- [ ] «Загрузить», «Настройки» и «История» открывают соответствующие экраны.
- [ ] «Выход» запрашивает подтверждение.
- [ ] Кнопки реагируют на наведение мыши.
